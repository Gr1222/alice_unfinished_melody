# 最新森林图：原图保留与 Blender 分层教程

本教程采用用户允许的省 token 路线：原图分区＋固定机位图片出图。工程是 **2.5D 图片卡片**，不是完整三维树木重建，也不会产生背面或可自由转动的镜头。原图位置、纹理和色彩由贴图保留。

## 交付与高清说明

- `images/forest-original-8k.png`：8192×4608 RGBA 原附件的无损副本，已校验文件 SHA-256 一致。
- `forest-latest-layered.blend`：已用 Blender 5.2.3 LTS 实际生成，原图纹理已打包在文件内，可移动到别的电脑。
- `images/blender-composite-preview.png`：实际 Blender 2048×1152 合成预览。
- `layers/`：洞口古树、中央树根、符文石碑、左下前景、右下前景五张区域 RGBA PNG，以及位置清单。
- `scripts/`：生成脚本与可用于导出手工修改结果的脚本。

这张附件已经达到 8K。本次没有 AI 补画、锐化、插值放大或重绘细节，避免改变场景。8K 文件尺寸不等于增加了原画信息；如果原画本来是低分辨率像素画的放大版，本次不会凭空恢复不存在的笔触。保留原图的要求优先。

Blender 预览经过渲染采样和色彩转换，不承诺与源文件逐像素相同；源图自身保持字节一致。完整原图用于成品背景时可直接使用无损原件。

## 第一次打开：不需要运行脚本

1. 将 ZIP 全部解压到可写文件夹，不要只提取 `.blend` 后删除其余资料。
2. 用 Blender 打开 `forest-latest-layered.blend`。场景应为 `Latest_Forest_Locked_Camera`。
3. 鼠标移到三维视窗，按小键盘 **0** 进入相机视角；没有小键盘可用菜单“视图 → 相机 → 活动相机”。
4. 按 **Z**，选择“材质预览”或“渲染”，查看原图。首次编译材质可能要稍等。
5. 按 **F12** 渲染。工程默认 8192×4608、100%，输出较慢时在输出属性中将百分比改成 25%，得到 2048×1152；50% 得到 4096×2304。
6. 渲染窗口使用“图像 → 另存为”保存 PNG。按 F12 本身不会自动写入 PNG。

不要移动相机、改变画幅或改用透视相机。卡片的空间深度仅用于分层组织，没有真实树后信息。物体变换和相机已锁定，防止误拖；编辑模式仍能修改几何。

## 用 Blender 继续细抠：先只做符文石碑

1. 先用“文件 → 另存为”保存 `forest-latest-working.blend`，保留交付版本。
2. 在 Outliner 展开 `30_STELE_REGION` 集合，选中其中同名网格；不要选中相机或 `00_MASTER`。
3. 在三维视窗按小键盘 0 回到相机视角，按 **Tab** 进入编辑模式。
4. 按 **K** 启动切割工具，沿石碑最外侧的黑色轮廓依次点击。把切线从已有网格边界的一端接到另一端，按 **Enter** 确认。
5. 切换面选择（使用键盘主区 3，或点击顶部的面选择图标），取消全选，再选中轮廓外多余的面，按 **X → 面** 删除。分段切掉外角，再逐步贴近轮廓，比一次绕整圈更容易。
6. 需要检查时按 Tab 回物体模式，再按小键盘 **/** 使用局部视图，只看这一张卡片。局部视图是工作视窗隔离，不影响 F12 的渲染集合。
7. 蘑菇、树根和树枝之间的空隙，也需要用 K 切开并删除对应面。保留黑色轮廓，不要把线条一并切掉。
8. **不要用 G/S/R 移动、缩放、旋转顶点来“贴边”**：这会带着旧 UV 拉伸画面。只做切割和删面，新顶点会继承原图的 UV 插值。
9. 若要检查透明渲染，用下一节脚本导出，再打开 `30_STELE_REGION.png` 检查。黑底不等于没有 alpha；可以在有棋盘格的图像查看器中查看。
10. 石碑完成后，再按相同办法处理中央树根和前景。枝条交错部分工作量较大，不要把区域切片误当作最终轮廓。

建议只细抠角色确实要从其背后走过的轮廓，其余内容继续烘焙在完整背景中，可节省制作工作。

## 导出修改后的结果

1. 确认当前激活的是 `Latest_Forest_Locked_Camera` 场景，并保存工作工程。
2. 切到顶部 **Scripting** 工作区，在文本编辑器点“打开”，选择 `scripts/export_latest_cards.py`。
3. 脚本顶部 `EXPORT_PERCENT = 25` 对应 2K。需要 4K 改为 50，需要 8K 改为 100。
4. 点文本编辑器的“运行脚本”（或鼠标在该编辑器内按 Alt+P）。
5. 脚本会先导出完整合成图，再分别导出每个网格，位置在工作 `.blend` 同目录下的 `exports/<时间戳>/`。不会重新生成网格，也不会覆盖你切好的轮廓。
6. 所有图层使用同样的画布大小和相机，因此保持左上角对齐即可叠回原图。先不要自行裁切；如果裁切，必须另行记录偏移。

脚本导出的 `00_MASTER.png` 仍是包含全部物体的原图，不是抹掉了树木的干净地面。只隐藏额外卡片时，背景中的同一棵树仍会存在，这是预期。

## 接入 Godot 时

完整原图用于静态背景；已细抠的前景放在角色之前。希望按脚底 Y 排序的物体需要单独设接地锚点，不能使用全画布图片中心作为脚底。此包尚未设置最终游戏碰撞或角色路线，也未修改已验证序章。

若要真正移动树木、打开图中原本被树挡住的位置或改变镜头，需要额外补画隐藏地面；只复制原图无法得到这些内容。当前保持固定机位和原图，可以先完成预渲染管线实验。

## 重新生成交付工程（会丢弃该输出文件中的手工修改）

只在新的空文件夹或备份后操作。在包根目录打开 PowerShell：

```powershell
& 'C:/Program Files (x86)/Steam/steamapps/common/Blender/blender.exe' --background --python-exit-code 1 --python ./scripts/build_latest_plate.py -- --root .
```

生成脚本会重写 `forest-latest-layered.blend` 和初始区域图，日常修改后的出图应运行 `export_latest_cards.py`。
